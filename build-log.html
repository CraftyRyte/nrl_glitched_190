Build log

Every bug we hit and how we fixed it. Our first build session was on 17 October 2026, and we had eight build sessions by 11 November.

Entry 01: Build stopped by a typo

ERROR: TankDrve instead of TankDrive stopped the build

FIXED: corrected the name and rebuilt

Entry 02: Line sensor not detected

ERROR: the Hub did not detect the line sensor

FIXED: reflashed the Hub

Entry 03: Motors ran reversed

ERROR: motors ran in the wrong direction

FIXED: inverted the left side in firmware

Entry 04: Inertial sensor distance error

ERROR: the inertial sensor over-read distance by about 1.6x

FIXED: distances now come from taped references, and the sensor is used for turns only

Entry 05: Line following on new tape

ERROR: line following needed recalibration on new tape

FIXED: recalibrate the sensor array at each venue

Decision: 300 RPM motors

We kept 300 RPM over 600 RPM because traction, not torque, limits pushing. We then upgraded to Grade A motors and new wheels.

Decision: no rotating arm

We rejected a 180° rotating arm because it was unstable and harder to drive.
